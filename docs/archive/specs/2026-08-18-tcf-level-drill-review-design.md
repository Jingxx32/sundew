# TCF 按等级训练与待复习中心 — 设计文档

日期：2026-08-18  
状态：已确认，待实施  
范围：TCF Canada 的 Compréhension orale（听力）与 Compréhension écrite（阅读）的**按等级训练**。不改变整套模拟考试模式。

## 1. 背景与目标

TCF Canada 的听力与阅读是两套独立题库；每套试题按 A1 至 C2 的难度逐步上升。Lumière 当前支持：

- 按 `skill × CEFR level` 汇总题目并做 drill；
- 点击选项后即时判分、显示讲解；
- 为每次 drill/exam 作答写入 `tcf_question_attempts`。

但当前 drill 更像“按资料顺序浏览题目”：所有题目固定排序，题号只有“做过/未做过”状态，无法区分猜对、答错与稳定掌握，也没有将不稳定题转为后续练习的闭环。

本设计将按等级训练定义为一个掌握导向系统：

```text
选择：听力 B2 / 阅读 B2
        ↓
系统安排一轮训练
        ↓
独立作答，记录正确性与把握度
        ↓
答错或不确定 → 待复习
        ↓
间隔后重新独立作答
        ↓
连续答对且确定 → 稳定掌握、低频巩固
```

### 1.1 成功标准

1. 用户能知道某等级中还有多少题“需要复习”，而非只知道做过多少题。
2. 猜对的题不能被误判为掌握。
3. 复习时用户先再次作答，再看历史答案与讲解；系统测量的是重新检索，而不是记忆答案位置。
4. 用户可以删除误操作产生的单次作答记录；删除后所有学习状态立即重新计算。
5. 听力与阅读的题目历史、待复习数量、掌握判断完全独立。

## 2. 产品边界与术语

### 2.1 本期范围

| 包含 | 不包含 |
|---|---|
| A1–C2 等级 drill 的调度、作答记录、待复习与复盘 | 整套模拟考试的计时、锁定与评分逻辑改造 |
| 单题历史、删除单次记录、重置单题记录 | 官方分数 / NCLC 换算 |
| 题目级掌握状态与按考点标签聚合 | 写作、口语题目的复盘机制 |
| 听力与阅读各自的复盘队列 | 通用跨项目 SRS 平台 |

### 2.2 定义

| 术语 | 含义 |
|---|---|
| 作答历史（attempt history） | 用户每一次独立提交答案的不可变记录；删除操作除外。 |
| 不确定（uncertain） | 用户在提交答案前主动标记“我在猜 / 没把握”。它是把握度，不是第五个选项。 |
| 待复习（needs review） | 当前题最近一次有效作答答错，或答对但标记不确定。 |
| 稳定掌握（stable） | 经至少若干次间隔复习后，连续答对且确定的题。阈值为可配置策略，不是原始事实。 |
| 复盘（review） | 对一题待复习题再次独立作答的学习行为；提交前不可见旧答案、正确答案和讲解。 |

## 3. 核心决策

| 编号 | 决策 |
|---|---|
| D-1 | 听力与阅读是独立训练线；任何统计和调度均以 `skill × level` 为边界。 |
| D-2 | “答对但不确定”在**正确率**中算对，但在**掌握与调度**中与答错等价。 |
| D-3 | 每次独立提交均新增作答历史；不得用新结果覆盖旧记录。 |
| D-4 | 主动查看答案不构成作答，不能写入正确记录或改变掌握度。 |
| D-5 | 默认删除操作只删除一条作答历史；“重置此题学习记录”是独立、高风险操作。 |
| D-6 | 题目级状态由作答历史推导。若未来为性能建立摘要表，它只能是可重建的派生缓存。 |
| D-7 | 第一版调度要简单、可解释、可验证；不引入黑盒 AI 或复杂 SRS 算法。 |

## 4. 用户体验

### 4.1 训练入口与训练轮次

用户仍从 TCF 首页选择：

```text
Compréhension orale / Compréhension écrite
  └── A1 / A2 / B1 / B2 / C1 / C2
```

进入某等级后，页面不应默认把全部题库当作一次无边界会话。用户选择一个训练轮次：

- `10 questions`：默认，适合日常学习；
- `20 questions`：较完整的练习；
- `À revoir`：只处理已到期的待复习题；
- `Toutes`：保留给浏览资料或集中练习，不作为默认。

中途离开时，当前轮次的本地进度应可恢复。未提交答案的题不产生历史记录。

### 4.2 单题作答

初始状态：

```text
Écoute · B2 · Question 4 de 10

[音频或阅读材料]
[ ] Je ne suis pas sûr·e / Je devine

A. ...
B. ...
C. ...
D. ...
```

“不确定”控件必须在选择答案前可见，可随时切换。选项点击仍可保持即时判分，但提交时须连同 `uncertain` 一并保存。

提交后：

| 结果 | 用户可见反馈 | 调度结果 |
|---|---|---|
| 答错 | `Incorrect — à revoir` + 正确答案、讲解 | 进入待复习 |
| 答对且不确定 | `Correct, mais à revoir` + 讲解 | 进入待复习 |
| 答对且确定 | `Correct` + 讲解 | 增加掌握进度 |

讲解应包括：正确答案为何正确、已选错误选项为何不对、题目所考查的能力标签。对听力题，讲解阶段才显示 transcript；训练阶段保持独立听辨。

### 4.3 主动查看答案

现有 `Afficher réponse` 保留为学习辅助，但行为必须改为：

1. 点击后展示答案与讲解；
2. 不写入 attempt；
3. 答案展示后禁用选项，不允许用户再点击正确选项制造一次“答对”记录；
4. 提供 `Question suivante` 或 `Réessayer plus tard`。

它不是失败，也不是掌握证据，因此不会让题目离开未作答/待复习队列。

### 4.4 题号导航与本轮摘要

不能再用一个绿色 `fait` 表示“做过”。它将作答次数误读成掌握度。

建议状态：

| 显示 | 含义 |
|---|---|
| 灰 | 本轮未作答 / 没有历史 |
| 红或橙 | 当前需要复习：最近作答错误或不确定 |
| 绿 | 当前稳定掌握（仅在满足掌握策略后显示） |
| 蓝 | 当前题 |

第一版若未引入稳定掌握阈值，可先使用“灰 / 待复习 / 已答”三态，且将“已答”与“掌握”分开命名。

训练导航顶部显示：`8 répondues · 3 à revoir`。轮次结束页显示：

```text
10 questions terminées
6 correctes · 2 correctes mais incertaines · 2 incorrectes
4 questions à revoir
[Revoir maintenant] [Retour au niveau B2]
```

### 4.5 待复习中心

待复习中心不是单纯的错题列表，而是一个可再次检索的队列。入口包括：

- 训练轮次结束页的 `questions à revoir`；
- TCF 首页各技能卡片的待复习数量；
- 等级训练页的 `À revoir` 轮次入口；
- 全局 TCF 复盘入口。

筛选维度：

```text
技能：全部 / 听力 / 阅读
等级：全部 / A1 ... C2
考点：全部 / 词汇 / 推断 / 细节 ...
状态：待复习 / 复习中 / 稳定掌握
```

#### 复盘卡片：先答后看

复盘页面第一屏只显示材料和新一轮选项，不显示上次作答、正确答案或讲解。提交后才依次显示：

```text
上次：答对但不确定（2026-08-18）
本次：答对且确定
你的答案：C
正确答案：C
考点：inference
讲解：...
```

用户可以选择“下一题”或返回队列。对错历史不是给用户背答案，而是帮助反思为何之前会误判。

### 4.6 单题作答历史与删除

题目详情/复盘反馈中提供“历史”面板：

```text
2026-08-18 · drill  · C · 答对但不确定   [删除]
2026-08-15 · review · B · 答错             [删除]
2026-08-10 · drill  · A · 答错             [删除]
```

`删除`只影响这一行，需轻量确认：

> 删除这次作答记录？该题的待复习状态和掌握度会立即重新计算。

二级危险操作 `重置此题学习记录` 删除该题全部 attempts，并让它回到“未接触”。必须要求明确确认，不放在常规列表的首要操作位置。

删除记录后，以下内容立即从剩余历史重新派生：题目状态、待复习数量、等级汇总、考点标签汇总和下一轮调度。

## 5. 调度与掌握策略

### 5.1 优先级

在一个固定的 `skill × level` 组内，默认训练轮次按以下优先级挑选题目：

1. 已到期的待复习题：最近一次作答答错或不确定；更久未复习、连续失败更多者优先；
2. 从未独立作答的题；
3. 复习中、但尚未稳定掌握的题；
4. 稳定掌握题：低频抽取，用于防遗忘。

同优先级内部随机打散，避免用户背诵资料套题的固定顺序。题库较小时需避免在同一轮次重复同一道题，除非用户主动选择“立即再做”。

### 5.2 第一版的可解释间隔

不必一开始实现完整 SRS。可使用以下默认策略，集中体现“间隔后重新检索”：

| 最近一次有效结果 | 下次可进入优先队列 |
|---|---|
| 答错 / 不确定 | 下一次训练；若已在本轮出现，则至少下一轮 |
| 第一次答对且确定 | 约 3 天后 |
| 第二次连续答对且确定 | 约 7 天后 |
| 多次连续答对且确定 | 低频巩固（例如 14 天以上） |

任何一次答错或不确定都会打断连续掌握计数，并重新归为待复习。具体天数是弱决策，应在实际使用中迭代；“先独立答、再间隔复习”的原则是强决策。

### 5.3 掌握状态的推导

对每道题，按 `answered_at` 由新到旧读取有效 attempts：

```ts
needsReview = !latest.correct || latest.uncertain
```

建议状态：

```text
无有效 attempt                         → 未接触
latest 为错或不确定                     → 待复习
latest 为答对且确定，但连续数未达阈值   → 复习中
连续答对且确定且满足间隔阈值            → 稳定掌握
```

“正确率”必须单独以 `correct` 聚合；不得把不确定答对改写成 `correct = false`。否则考试表现与学习信心会被混淆。

## 6. 数据设计

### 6.1 原始事实：`tcf_question_attempts`

现有表已经记录 `questionId`、`mode`、`chosen`、`correct`、`answeredAt`。扩展：

```text
uncertain  boolean NOT NULL DEFAULT false
```

`mode` 扩展为：

```text
drill | review | exam
```

其中：

- `drill`：按等级训练的普通作答；
- `review`：在待复习中心重新作答；
- `exam`：整套模拟作答，保持现有语义。

每次独立提交新增一行。主动显示答案、切换题目、播放音频等行为均不写入行。

### 6.2 删除接口语义

需要两个受限 server action：

```text
deleteTcfQuestionAttempt(attemptId)
resetTcfQuestionLearningHistory(questionId)
```

前者仅删除一行；后者仅删除指定 `questionId` 的全部 attempts。两者不删除 `tcf_questions`、题库内容、其他题目的记录，且删除后需要 revalidate 相关 TCF 页面与进度页面。

### 6.3 派生状态

初期由 attempts 查询实时计算每题的：

```text
attemptCount
correctCount
uncertainCount
lastAnsweredAt
latestCorrect
latestUncertain
consecutiveConfidentCorrect
nextReviewAt
status
```

当查询规模成为问题时，可增加 `tcf_question_mastery` 摘要表。摘要表必须可由 attempts 全量重建；attempts 始终是事实来源。

### 6.4 考点标签

继续使用 `tcf_questions.skill_tags`，它与写作错误 taxonomy 分离。一个题目可以有主、次考点；复盘中心按标签筛选，统计面板按标签聚合“待复习数 / 有效作答数 / 正确率”。未打标题目仍应可练、可复盘，只是不出现在具体标签筛选里。

## 7. 页面与组件影响

| 位置 | 改动 |
|---|---|
| `/tcf` | 显示每个技能的待复习数量；保持按技能分开。 |
| `/tcf/drill` | 加轮次选择、题目调度、答前不确定控件、本轮摘要与更新后的题号状态。 |
| `DrillRunner` | 提交时保存 `uncertain`；主动看答案后禁止写入“正确作答”；支持本轮完成态。 |
| `LevelNav` | `done` 改为派生学习状态，文案从 `fait` 改为 `répondues`/`à revoir`。 |
| 新的复盘页面 | 提供筛选队列、先答后看、历史面板、单条删除和重置入口。 |
| `/progress` | 后续可增加 TCF 技能 × 等级 × 考点的待复习与稳定度汇总；不是本期阻塞项。 |

整套模拟（`/tcf/exam`）不显示“不确定”，也不将其作答历史带入等级训练调度的掌握判断，除非未来明确决定使用 exam 结果作为学习信号。第一版建议 exam 记录保留用于成绩历史，drill/review 记录用于学习调度，避免模拟表现与学习流程混杂。

## 8. 验收标准

1. 在“听力 B2”答错题目后，题目立即出现在“听力 B2 · 待复习”中，不影响“阅读 B2”。
2. 在“阅读 A2”答对且勾选不确定后，正确率增加，但待复习数也增加。
3. 主动显示答案后点击正确选项不会产生一次 `correct = true` 的 attempt。
4. 复盘题在提交前不展示上一次答案、正确答案和讲解；提交后正确显示三者。
5. 删除某条 attempt 后，该题状态和待复习数量按剩余历史即时更新。
6. 重置一题后，该题回到未接触，其他题的历史不受影响。
7. 同一轮训练不重复同一道题；题目顺序不再固定等同于 test/orderIndex。
8. 无论刷新或换浏览器，作答历史与待复习状态一致。

## 9. 实施顺序

1. 迁移：`uncertain` 列；扩展 attempt mode 为 `review`；补全删除 action 与授权边界。
2. 查询层：获取题目历史、推导题目状态、生成固定 `skill × level` 的调度队列。
3. 改造 DrillRunner：不确定控件、查看答案语义、状态导航、10/20 题轮次和结束摘要。
4. 新建待复习中心与单题历史面板；接入删除单条/重置单题操作。
5. 接入 `skill_tags` 的筛选与聚合；根据真实使用数据调整间隔和稳定掌握阈值。

## 10. 明确不做

- 自动宣称用户已达到官方 TCF / CEFR 成绩；
- 用 AI 决定题目是否掌握或决定复习顺序；
- 因为答对一次就移除题目；
- 删除题库题目或删除整套模拟考试成绩；
- 把阅读和听力的正确率、待复习状态合为一个“总掌握度”。

## 11. 与旧设计的关系

本文件补充并在以下决策上**替代** `2026-07-06-tcf-error-loop-design.md` 的早期设想：

- 旧文档将“答题历史是数据资产”解释为不提供清除记录按钮；本设计确认应保留历史，但允许用户删除误操作的**单次记录**，以及经二次确认后重置**单题**历史。
- 旧文档只以 `correct` 判断错题；本设计新增 `uncertain`，并规定答对但不确定与答错同样进入待复习。
- 旧文档的 `ordre / malin / erreurs` 是全题库浏览模式；本设计优先引入有边界的 10/20 题训练轮次与待复习中心。旧模式若保留，应使用本文件的掌握状态与调度规则。
