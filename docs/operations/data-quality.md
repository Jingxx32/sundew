# Data Quality

## TCF listening source issues

Some TCF listening records require source verification before explanation work continues. The detailed list, evidence, and affected question locators remain in [the 2026-09-04 TCF listening data audit](../tcf-listening-data-audit-2026-09-04.md).

For affected records, leave `explanation` empty until the original TCF source material is checked. Do not normalize an internally inconsistent answer key by guessing.

## Operating rule

Imported content is not automatically authoritative. When extracted options, answer keys, transcripts, or media conflict, preserve the evidence, identify the affected locator, and verify against the original source before changing learner-facing data.
